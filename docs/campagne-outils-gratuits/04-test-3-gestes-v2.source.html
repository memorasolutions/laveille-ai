Geste 3

Ce qui reste identifie-t-il encore quelqu’un?

  1. Une personne du milieu reconnaîtrait-elle quelqu’un avec ces indices?
  2. Ces détails sont-ils nécessaires à votre demande? Sinon, retirez-les.
  3. Peut-on les généraliser? « Lévis » devient « une succursale », « D-4471 » devient « un dossier ».

Si le doute persiste, ne collez pas. Retravaillez le texte.

Ce tri vous revient, parce que vous seul savez ce que vos codes internes désignent. Ensuite seulement : « Copier pour l’IA ».

Deux familles à ne pas confondre

Pourquoi le dernier tri vous revient

  • Nom, téléphone, courriel identifiants DIRECTS : ils se reconnaissent à leur forme, une machine peut les attraper
  • « D-4471 », « succursale de Lévis » identifiants de CONTEXTE : ils n’identifient que pour qui connaît le milieu

Aucun logiciel n’a accès à ce contexte-là. Vous, oui. C’est tout le sens du troisième geste.
