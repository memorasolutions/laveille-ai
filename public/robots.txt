# robots.txt - laveille.ai
# SEO + GEO/AEO 2026 (Generative Engine Optimization)
# Strategie : opt-in maximal pour les robots d'IA legitimes (entrainement, recherche,
# agents) afin d'etre cite dans ChatGPT, Claude, Perplexity, Gemini, Copilot.
#
# DEUX REGLES DE LECTURE A CONNAITRE AVANT DE MODIFIER CE FICHIER.
#
# 1. LES GROUPES N'HERITENT PAS. D'apres la RFC 9309 (section 2.2.1), un robot n'obeit
#    qu'a UN SEUL groupe : le plus specifique qui le nomme. Un "Disallow" ecrit sous
#    "User-agent: *" ne protege AUCUN robot qui possede son propre groupe. C'est
#    pourquoi les memes interdictions sont repetees dans chaque groupe. Ne jamais les
#    retirer de l'un d'eux en croyant qu'elles sont heritees d'ailleurs.
#
# 2. L'ORDRE DES LIGNES COMPTE. Deux conventions coexistent : "la premiere regle qui
#    correspond gagne" (historique, encore appliquee par beaucoup de robots) et "la
#    regle la plus specifique gagne" (RFC 9309, Google). L'ordre retenu ici - exception
#    precise, puis interdictions, puis "Allow: /" en dernier - est le seul qui donne le
#    meme resultat dans les deux. Remonter "Allow: /" en tete rouvrirait tout le site,
#    en silence, pour les robots de la premiere famille.
#
# L'opt-in porte sur le contenu PUBLIC, jamais sur les espaces prives. Les pages
# /decido/ portent en plus une balise "noindex" : celle-ci s'adresse aux moteurs de
# recherche et ne lie pas la recolte d'entrainement. Les deux sont necessaires.
#
# Verrouille par Modules/Decido/tests/Feature/DecidoNonIndexableTest.php
# Maintenu par MEMORA solutions (info@memora.ca).
