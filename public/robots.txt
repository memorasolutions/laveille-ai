# robots.txt - laveille.ai
# SEO + GEO/AEO 2026 (Generative Engine Optimization)
# Stratégie : opt-in maximal pour les robots d'IA légitimes (entraînement, recherche,
# agents) afin d'être cite dans ChatGPT, Claude, Perplexity, Gemini, Copilot.
#
# DEUX RÈGLES DE LECTURE A CONNAÎTRE AVANT DE MODIFIER CE FICHIER.
#
# 1. LES GROUPES N'HÉRITENT PAS. D'après la RFC 9309 (section 2.2.1), un robot n'obéit
#    qu'a UN SEUL groupe : le plus spécifique qui le nomme. Un "Disallow" écrit sous
#    "User-agent: *" ne protège AUCUN robot qui possède son propre groupe. C'est
#    pourquoi les mêmes interdictions sont répétées dans chaque groupe. Ne jamais les
#    retirer de l'un d'eux en croyant qu'elles sont héritées d'ailleurs.
#
# 2. L'ORDRE DES LIGNES COMPTE. Deux conventions coexistent : "la première règle qui
#    correspond gagne" (historique, encore appliquée par beaucoup de robots) et "la
#    règle la plus spécifique gagne" (RFC 9309, Google). L'ordre retenu ici - exception
#    précise, puis interdictions, puis "Allow: /" en dernier - est le seul qui donne le
#    même résultat dans les deux. Remonter "Allow: /" en tête rouvrirait tout le site,
#    en silence, pour les robots de la première famille.
#
# L'opt-in porte sur le contenu PUBLIC, jamais sur les espaces privés. Les pages
# /decido/ portent en plus une balise "noindex" : celle-ci s'adresse aux moteurs de
# recherche et ne lie pas la récolte d'entraînement. Les deux sont nécessaires.
#
# Verrouillé par Modules/Decido/tests/Feature/RobotsTxtProtegeLesSondagesTest.php
# (le « noindex » des pages de vote est verrouillé, lui, par DecidoPagePubliqueTest.php)
